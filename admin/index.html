Połączenie z repozytorium GitHub

Panel zapisuje zmiany bezpośrednio w repozytorium, z którego GitHub Pages publikuje stronę. Po opublikowaniu strona odświeża się zwykle w 1–2 minuty.

Jak utworzyć token? (jednorazowo, ok. 2 minuty)
  1. Zaloguj się na GitHub i otwórz Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Nazwa: np. Panel realizacji. Expiration: wybierz np. 1 rok.
  3. Repository access → Only select repositories → wybierz repozytorium ze stroną.
  4. Permissions → Repository permissions → Contents → Read and write. Nic więcej nie zaznaczaj.
  5. Kliknij Generate token, skopiuj go i wklej powyżej.

Token jest zapisywany tylko w tej przeglądarce (localStorage) i wysyłany wyłącznie do api.github.com. Nie udostępniaj go nikomu. Na komputerze, z którego korzysta wiele osób, po pracy kliknij „Wyloguj”.
