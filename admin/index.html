Pierwsze uruchomienie. Połącz panel z repozytorium GitHub i ustal hasło – później do logowania wystarczy już tylko hasło.

Jak utworzyć token? (jednorazowo, ok. 2 minuty)
  1. Otwórz GitHub → Fine-grained tokens → Generate new token.
  2. Nazwa: np. Panel realizacji. Expiration: np. 1 rok.
  3. Repository access → Only select repositories → wybierz repozytorium ze stroną.
  4. Permissions → Repository permissions → Contents → Read and write. Nic więcej.
  5. Generate token, skopiuj i wklej powyżej.

Zmień hasło lub token

Token GitHub jest przechowywany w repozytorium wyłącznie w postaci zaszyfrowanej Twoim hasłem (plik admin/auth.json). Bez hasła nie da się go odczytać, dlatego używaj długiego hasła, którego nie masz nigdzie indziej.
